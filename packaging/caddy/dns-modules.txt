# libdns DNS provider modules compiled into rynas-caddy for ACME DNS-01 (wave W2:
# own-domain wildcard certificates and rynas-managed DNS records, docs/research/web-access.md
# §3 and §11). Built only with `build.sh --dns`; W1 needs none (no ACME: local names use the
# rynas local CA).
#
# Each line is `<module path>@<version>`: build.sh refuses a line without a pinned version,
# so a build is reproducible. Pinned on 2026-11-07 (wave W2): each module's latest tag, all
# on libdns 1.x (the API Caddy 2.10+ / certmagic 0.24+ use; Caddy 2.11.9 requires libdns
# v1.1.1, so Go's minimal version selection lifts the older ones to it). Checked with the
# GitHub tags and each module's go.mod (https://github.com/caddy-dns/<name>/tags), then built
# with `build.sh --dns --validate` (rynas-caddy list-modules shows dns.providers.*).
#
# - hetzner: the /v2 module talks to the Hetzner Cloud API (the old dns.hetzner.com API was
#   shut down in May 2026; https://docs.hetzner.com/networking/dns/faq/beta).
# - duckdns: v0.5.0 still declares libdns v1.0.0-beta.1; it builds against v1.1.1.
# - digitalocean has no tag: a pseudo-version of its last commit (2025-06-06).
# - every module but acmedns (password only) replaces `{file.*}`/`{env.*}` placeholders in
#   its credential fields in Provision, so rynasd never writes a secret into the JSON.

Vaultwarden is an independent, lightweight implementation of the Bitwarden server API.
The official Bitwarden apps, browser extensions and the web vault work with it: passwords,
organizations, sends, attachments and two-factor login, in a few tens of megabytes of RAM.

Browsers allow the cryptography the vault needs only on secure (HTTPS) pages, so publish it
through the rynas web access module before creating accounts.

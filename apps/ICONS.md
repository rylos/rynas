# App icons

The `metadata/icon.svg` files come from [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons)
(homarr-labs), distributed under the Apache License 2.0.

The logos are trademarks of their owners and appear here only to identify each app. Their
use does not imply endorsement. Dockhand's icon is the ship of the logo in its own repository (`src/images/logo.svg`,
without the wordmark). JDownloader's is the Dashboard Icons logo, whose SVG wraps a
bitmap: embedded at 96 px so the file stays small (the icon CSP allows `data:` images).

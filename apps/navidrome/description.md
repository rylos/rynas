Navidrome turns a shared folder of music files into a personal streaming service: a fast
web player, playlists, smart playlists and multiple users. It speaks the Subsonic API, so
dozens of phone and desktop apps can play from it, with transcoding for slow connections.

Map the music shared folder read-only. New files are picked up as they arrive (file watcher),
with no periodic scan, so the hard disks holding the music can spin down.

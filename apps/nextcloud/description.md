Nextcloud is a content collaboration platform: file sync and sharing with desktop and
mobile clients, calendars and contacts (CalDAV/CardDAV), and hundreds of apps.

This entry uses the official community image with MariaDB and Redis, installed
automatically with the admin account you choose. The All-in-One image is not used because
it manages its own containers and proxy. User files live in their own folder, separate from
the code and configuration.

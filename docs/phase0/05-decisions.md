| D-ZRAM | zram configuration | lz4 · zstd · lz4+zstd recompression · zswap | **auto profile by RAM**: ≤ 12 GB → **zstd** (ratio ~3-3.9:1 vs ~2.1-2.6:1; RAM saved matters more than µs latency, swap-in is rare on a NAS), > 12 GB with a fast CPU → **lz4** (fastest, ratio irrelevant); size `min(ram, 8 GB)` up to 8 GB RAM, then `ram / 2` capped at 16 GB; `swap-priority=100`, `vm.swappiness=180`, `vm.page-cluster=0`; zram only when there is no disk swap (with SSD/NVMe swap offer zswap instead, never both).
